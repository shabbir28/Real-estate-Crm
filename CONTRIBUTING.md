# Contributing to Real Estate CRM

Thank you for your interest in contributing to the Real Estate CRM project! We welcome contributions from developers of all skill levels.

## How to Contribute

### 1. Reporting Bugs
- Use the repository's "Issues" tab to report bugs.
- Provide a clear description and steps to reproduce the issue.

### 2. Suggesting Features
- Open an issue with the "feature-request" tag.
- Explain why the feature is needed and how it would work.

### 3. Pull Requests
- Fork the repository.
- Create a new branch: `git checkout -b feature/your-feature-name`.
- Commit your changes: `git commit -m 'Add some feature'`.
- Push to the branch: `git push origin feature/your-feature-name`.
- Open a Pull Request against the `main` branch.

## Development Setup

### Backend
1. `cd backend`
2. `npm install`
3. Create `.env` file from `.env.example`.
4. `npm run dev`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm start`

## Coding Standards

### JavaScript/React
- Use functional components and hooks.
- Follow the existing folder structure.
- Use Tailwind CSS for styling.
- Ensure proper error handling in async/await blocks.

### Commits
- Use descriptive commit messages (e.g., `fix: resolve login bug`, `feat: add lead export`).

## Communication
If you have questions, please reach out via GitHub Issues or contact the project maintainers.
